LittleLinguist is an interactive language-learning application for children that combines artificial intelligence, speech technologies and playful activities to teach English through stories. Rather than relying on traditional exercises, it builds a short adventure in which the child follows an AI-generated story, takes a picture of an object that becomes part of it, traces words to practise writing, uses speech recognition to practise pronunciation, answers reading comprehension questions and follows the narration to practise listening. Each activity can be enabled or disabled from the settings, so the experience adapts to what the child needs to work on at any given moment.

The application starts on the home page, where the child chooses between Story Adventure and Photo Adventure. Story Adventure leads straight to story generation, while Photo Adventure adds two intermediate steps — taking a photo and recognising the object it contains — before generating a story that includes that object. From there both routes converge: the generated story leads into the writing, reading and pronunciation activities, the story is then narrated so the child can practise listening, and the cycle repeats with the next part of the story for as long as the adventure lasts.

All the artificial intelligence runs locally, which removes the need for external AI APIs during normal use. Gemma 3 1B generates the stories and the comprehension questions, SmolVLM 256M identifies objects in photographs, Piper narrates the story using the English voice en_US-lessac-medium, and Vosk records the child's speech during the pronunciation activity and compares the recognised word with the target word. The application is built in C# on .NET, with Avalonia UI for the interface, LLamaSharp to run the language model, and OpenCV and FFmpeg for image and audio processing. It requires the .NET SDK, Git and FFmpeg, plus a working microphone and camera; installation begins by cloning the repository with git clone <REPOSITORY_URL> and entering the directory with cd LittleLinguist, then running the included script (chmod +x install-resources.sh followed by ./install-resources.sh on Linux and macOS), which downloads Gemma 3 1B, SmolVLM, Piper with its voice model and the Vosk resources. Finally, dotnet restore, dotnet build and dotnet run restore the dependencies, compile the project and launch the application.

There are several directions in which the project could grow: adding characters, locations and actions to increase story variety; improving generation to reduce incoherent content and stop the model from leaking parts of the prompt into the text; adapting stories to each child's level by using the results of the activities to adjust vocabulary and difficulty dynamically; and adding further types of activities and deeper personalisation. LittleLinguist was developed by Pau Martínez Franch, Irene Mas Ramírez, Laia Moreno Plata and Aarón Quintanilla Padilla at the Facultat d'Informàtica de Barcelona (FIB) of the Universitat Politècnica de Catalunya (UPC), as part of a hackathon project.
